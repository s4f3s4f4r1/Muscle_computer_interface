This project presents a Muscle–Computer Interface (MCI) based automated system designed to 
control the movement of a robotic car using human muscle signals. The main goal of the system 
is to convert muscle activity into movement commands, allowing users to operate the robotic car 
in a natural and hands-free manner. The overall process is carried out in three major stages: muscle 
signal acquisition, feature extraction, and movement classification. 
In the first stage, muscle activity signals are collected from different users using surface electrodes 
placed on the skin. These signals are generated when the muscles contract while performing 
specific gestures. Since raw signals often contain unwanted noise and interference, they are pre
processed using signal conditioning techniques to improve their quality and reliability. 
After pre-processing, important characteristics of the signals are extracted using both time-domain 
and frequency-domain analysis methods. These features help identify unique patterns associated 
with different muscle movements. Once the relevant features are obtained, they are provided to a 
supervised machine learning model that is trained to recognize and classify the gestures. 
Based on the classified signals, the robotic car performs corresponding actions such as moving 
forward, backward, turning left, or turning right. The proposed MCI-based control system 
demonstrates reliable performance and provides an effective alternative to traditional manual 
control methods. 
This technology has significant potential in various real-world applications, including assistive 
systems for physically challenged individuals, rehabilitation and healthcare devices, hands-free 
control in hazardous environments, and advanced human–machine interaction systems. Overall, 
the project highlights how muscle-based interfaces can be used to create intelligent, practical, and 
user-friendly control systems for robotic applications.
